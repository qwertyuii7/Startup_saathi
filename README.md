## 🌟 Overview

**Startup Saathi** is an AI-powered platform designed to seamlessly connect startup founders with relevant government schemes, grants, and incubators. It transforms the overwhelming process of navigating thousands of PDFs and complex bureaucratic clauses into a beautifully simple, intelligent, and context-aware experience.

Built with a state-of-the-art **Copilot** at its core, Startup Saathi analyzes your startup's profile—automatically extracting key details from your DPIIT certificate or Pitch Deck—and deterministically matches you with the right opportunities. 

## ✨ Key Features

- 🧠 **Context-Aware Copilot (`⌘K`)**: A built-in AI assistant that reads your current screen. Whether you're exploring incubators or checking your scheme eligibility, Saathi knows exactly what you're looking at and provides intelligent answers instantly.
- 🎯 **Deterministic Eligibility Matching**: Replaces generic AI hallucinations with 100% verified citations. We highlight exactly *why* you are eligible based on official government clauses.
- ⚡ **Interactive Eligibility Simulator**: Test "what-if" scenarios. Change your revenue or age metrics and see how your eligibility for various schemes changes in real-time.
- 📂 **Smart Document Parsing**: Upload your DPIIT certificate or Pitch Deck, and our document intelligence automatically populates your profile (Sector, Stage, Revenue).
- 🚀 **Drafting & Compliance**: Identify missing documents instantly (Gap Analysis) and let the AI draft your application automatically.

## 🛠️ Tech Stack

Startup Saathi is built for performance, beautifully designed, and highly responsive.

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: TypeScript

## 🖥️ Local Development

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/qwertyuii7/Startup_saathi.git
   cd Startup_saathi/WEB_APP
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🎨 Design Philosophy

Startup Saathi strictly adheres to a premium, non-overwhelming Copilot aesthetic. 
- **Progressive Disclosure**: Information is revealed exactly when you need it.
- **Split-Screen Workspace**: The AI doesn't block your screen; it works *alongside* you in a beautiful right-side drawer.
- **Calm UI**: Vibrant purples, fuchsias, and emeralds strictly used for interactive/success elements, layered over a structured, 1px-grid layout.
